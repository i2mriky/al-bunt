# Al Bunt · البنط — direct booking page (concept)

Self-initiated concept by Nour Mohamed (NM*), part of bio-hub (https://i2mriky.github.io/bio-hub/). Not a real hotel.
One static page: 7 rooms by name; each room opens WhatsApp with the room's name in the message.

- `index.html` · `assets/style.css` · `assets/app.js` (no network calls, no storage)
- WhatsApp number = `WA` at the top of `assets/app.js` (+ the no-JS links in `index.html`)
- Images AI-generated (Nano Banana), fonts = Readex Pro (OFL), self-hosted.
